Space-time planning with endogenous occupancy

SnakeGuide

November 2026 · 4 minute read · Explanatory synthesis

vector figure/interactive figure/references/bibtex/text/

Abstract

Space-time search augments a cell with an arrival time to represent changing occupancy. In Snake, future occupied cells depend on the agent’s own actions and on growth, so a reservation schedule cannot generally be treated as fixed. We compare release-time approximations with full-body successor states and identify the guarantee each representation can support.

Key point. Time helps only when the state also preserves the history needed to predict future occupancy.

1.A route through changing occupancy

Ordinary grid search uses a cell as a vertex. If an obstacle moves, reaching that cell at time three can differ from reaching it at time eight. A space-time graph therefore represents a vertex as (cell, time) and connects feasible transitions across successive time layers.

This is useful when future occupancy can be supplied as reservations. Silver’s cooperative pathfinding paper develops this idea for multiple agents. Applying it to Snake requires an extra argument: the snake’s future occupancy is generated by the same actions being planned.

Method references: [1]

2.Release-time planning is an approximation

A current body provides nominal release times under a no-growth assumption. A planner can reject arrivals earlier than the recorded release time. This captures one important constraint that static search misses.

But two paths reaching the same cell at the same time may leave different body trails. Merging them into one (cell,time) vertex discards information that can determine the legality of the next action. A time coordinate by itself does not repair an incomplete state.

3.Search the state that determines legality

An exact forward search can store the ordered body, direction, food, and any pending growth at each node. Each outgoing edge invokes the transition function. States may be merged only when they are equivalent for the future task being solved.

This state space is far larger than the board. A practical planner may cap depth, cap memory, or use a beam. Each cap changes the guarantee: failure to find a route under a budget is not proof that no route exists.

4.Choose the guarantee before the representation

If the goal is a cheap warning signal, a release-time approximation may be appropriate. If the goal is validating a proposed short action sequence, exact simulation is inexpensive. If the goal is proving that every continuation fails, exhaustive state reasoning or a separate theorem is needed.

In experiments, separate “no path in the abstraction,” “budget exhausted,” and “proven dead under the exact model.” These outcomes mean different things. The lab’s pathfinding experiment deliberately uses a static graph, so its shortest-path label applies only to that frozen graph.
