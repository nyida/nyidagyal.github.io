# SnakeGuide

The static website at https://snakeguide.org is published from this repository's root.

The editable Next.js/React/TypeScript project is included in `SnakeGuide-Source.zip`. Extract that archive into a local checkout of this repository, then follow its README to edit and rebuild. The resulting `site/` directory contains the source, and `npm run pages` regenerates the static root files. Keep the existing CNAME and .nojekyll files.

This edition includes 18 technical articles, scientific figures, source references, an interactive laboratory, and browser-generated experiment exports. The homepage and About links for Nyida Gyal point to the Speedrun profile.
