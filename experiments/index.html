Static search under matched inputs

A reproducible comparison of BFS, Dijkstra, and Manhattan A*

SnakeGuide · November 2026
results/protocol/source code/limitations

Abstract

We compare three graph-search procedures on identical seeded grids. BFS minimizes the number of moves; Dijkstra and A* minimize a nonnegative entering cost. Every run exports the generated obstacles, terrain, seeds, and per-case outcomes. This controlled experiment isolates route cost and expansion count. It does not evaluate a moving Snake controller, trained policy, or survival rate.

2. Experimental protocol

Environment
10 × 8 grid, solid boundaries, four-neighbor movement. Start (0, 0); goal (9, 7). Both are always free and have unit entering cost.
Generator
Each case initializes an unsigned 32-bit LCG with initial seed + case index. Update: x ← (1664525x + 1013904223) mod 2³²; output x / 2³².
Sampling
Scan cells row by row, excluding endpoints. An obstacle draw below 0.15 blocks the cell. Otherwise a second draw below 0.25 marks costly terrain when weighted mode is enabled. The second draw is consumed in either cost mode.
Costs
Terrain costs 5 to enter; other cells cost 1. BFS ignores these weights when selecting a route but reports its actual weighted route cost.
Ordering
Neighbors are generated right, down, left, up. Dijkstra and A* use a stable sort on g + h, with insertion order for ties. A* uses Manhattan h; Dijkstra uses h = 0.
Termination
Stop when the goal is removed from the frontier or the frontier becomes empty. Count each first expansion, including the goal. Ignore duplicate entries after a cell has been closed.
Aggregation
Report the number of reachable cases and arithmetic means over those cases. No confidence interval or population-level performance claim is inferred from this fixed finite suite.

4. Scope and limitations

The frontier uses an array and stable sorting for transparency. Expansion counts are algorithmic measurements; they are not runtime benchmarks. The generator is a specified educational test distribution, not a representative sample of Snake gameplay. Repeated fixed-seed execution is deterministic and does not add independent evidence.

Static routing omits body motion, growth, food respawn, and policy decisions after reaching the goal. Those features require a separate full-game evaluation, described in the evaluation protocol note.
